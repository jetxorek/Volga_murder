# ADR-002. noteSpans — ссылки по ID, реестр в noteMatrix.ts

**Дата:** 2026-01-20
**Статус:** Принято

## Контекст

В P1b схема `SceneNode.noteSpans` была `z.array(NoteSpanSchema)` — встроенные объекты. Это приводит к дублированию при появлении одной заметки в нескольких сценах и усложняет валидацию ссылочной целостности.

## Решение

- `SceneNode.noteSpans` — `z.array(z.string().min(1)).optional()` (IDs).
- Единственный источник `NoteSpan` — `src/data/noteMatrix.ts` (реестр `Record<string, NoteSpan>`).
- Валидация: каждый ID в `noteSpans` существует в реестре; каждый `truthKey` в реестре существует в `truthTable[target][category]`.

## Последствия

- `scene.ts` — правка одной строки (не ломает существующие тесты P1b, тесты используют `noteSpans` без встроенных объектов или не используют вовсе).
- Дублирование заметок исключено.
- `noteMatrix.ts` становится «оглавлением» всех заметок — удобно для дизайнера и ревьюера.

## Файлы

- `src/schemas/scene.ts` — правка `noteSpans` в `NarrationNodeSchema` и `DialogueNodeSchema`.
- `src/data/noteMatrix.ts` — реестр заметок (будет в P2b).
